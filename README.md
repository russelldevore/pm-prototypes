How I build
Map the workflow first. Every app here started as a sketch of what the user actually does today, then found the one step worth automating.
Degrade gracefully. Apps that sync through Supabase fall back to local-only mode when offline, with no errors and no lost data.
Ship, watch, fix. Usage logging (e.g., per-coach seeded links in Flag Flow) shows how the tool is actually used, not how I assumed it would be.
