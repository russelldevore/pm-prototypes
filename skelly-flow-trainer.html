Build notes / decisions to QA
  • Default ball targets on plays without a named receiver (i.e. not X Now/Y Now): Doubles Bubble Slant → Z, Trips Bubble Slant → X, Doubles Bubble Screen → Z, Doubles Deep Switch → X. All run plays → RB. Flag any you'd rather see targeted differently.
  • Ball is now only visible while actually in flight on a pass (with the "Ball in the air" badge). Run/handoff plays never show a ball icon at all — the handoff is treated as instant, so there's no separate "in transit" moment to display, and the green highlight on the RB is the only indicator. Flag if you want a brief visible handoff moment too.
  • Speed select (Slow/Normal/Fast = 0.1/0.18/0.3) is wired as "fraction of the full play per second," so Slow = longer total playback, Fast = shorter — I don't have Flag Flow's actual formula, so this is a guess at matching the feel, not a verified match.
  • Floating controls bar is genuinely draggable now (grab the ⠿ handle) and minimizes down to just the play button via the ⌄ toggle. Flip formation isn't in your pasted Flag Flow markup, so I added it into this bar as an extra button since the app still needs it somewhere.
  • Step back/forward move in fixed 5% increments of the play — not tied to real yardage or a frame count, just a reasonable default.
